# 本地 RAG 路线图

## 目标

为咽喉癌辅助评估系统提供一个离线、可审计的知识检索闭环：仅摄取显式导入的外部知识文件，使用本地 `Qwen3-Embedding-0.6B` 生成向量，并以 SQLite FTS5/BM25 与向量检索的混合召回为现有 `rag_search` 提供可追溯引用。

## 非目标

- 不抓取或同步公网知识。
- 不将患者病例资料写入知识库。
- 不使用在线 embedding 服务。
- 首版不包含 reranker、OCR、复杂权限体系或多租户管理。
- 不根据检索结果自动生成未经医生复核的临床结论。

## 里程碑

### 1. 数据契约与存储

- 定义知识文档、版本、分块、嵌入和摄取记录的数据模型。
- 扩展 SQLite schema，并保留既有文件化 KB 的兼容读取能力。
- 要求来源、发布日期、适用癌种、证据等级、审核状态和内容哈希。

验收：同一版本的知识块与其来源、审核状态和历史引用可以稳定回查。

### 2. 文档摄取与分块

- 支持 Markdown、TXT、DOCX 和文本型 PDF。
- 提取正文与页码/标题位置，清洗重复段落和无效文本。
- 使用标题优先、长度兜底、少量重叠的稳定分块策略。
- 提供去重、增量导入和失败可追踪的摄取任务。

验收：导入同一文件不产生重复块；修改文件仅处理变化部分；每个块可定位至原文件位置。

### 3. 本地向量服务与索引

- 将 `Qwen3-Embedding-0.6B` 部署为仅绑定本机地址的 embedding 服务。
- 实现应用侧适配器、健康检查、批量请求、超时和重试边界。
- 区分文档与查询的模型指令模板；按内容哈希增量生成 1024 维向量。
- 提供可重建索引的命令与进度记录。

验收：断网环境可完成摄取与查询；模型不可用时明确降级，不生成虚假向量结果。

### 4. 混合召回

- 用元数据过滤知识版本、审核状态和癌种/亚部位。
- SQLite FTS5/BM25 负责精确术语检索，本地余弦相似度负责语义检索。
- 用 Reciprocal Rank Fusion 融合两个候选列表。
- 返回融合排名、各路排名、匹配词和引用位置。

验收：术语查询与同义改写均能命中预期知识块，结果可解释、可复现。

### 5. Agent 接入、测试与运维

- 将现有 `rag_search` 切换到混合检索器，保持 `citation → EvidenceModel → report` 链路不变。
- 补齐解析、去重、版本隔离、索引、降级和召回排序测试。
- 提供模型启动、文件导入、索引重建和故障排查文档。

验收：评估报告绑定实际使用的知识版本和引用块；完整回归测试通过。

## 后续候选

- 本地 `Qwen3-Reranker-0.6B` 对融合候选进行二次重排。
- 扫描 PDF 的 OCR 管线。
- 知识库审核 UI、角色权限与导入审批流。
